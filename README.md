
# User Configuration Manager

A Python-based application that allows users to manage their settings such as theme, language, and notifications.

## Features

- **Add Settings:** Add new configuration preferences.
- **Update Settings:** Modify existing preferences.
- **Delete Settings:** Remove specific preferences.
- **View Settings:** Display all current settings formatted.

## How to Run

1. Ensure you have Python installed.
2. Run the script using: `python main.py`
